# AFTER HOURS — Isaac & Abel

An interactive fictional phone experience for Isaac Huang and Abel Erland. Built with plain HTML, CSS and JavaScript: no build tools, package installs, or backend required.

## Run locally
Open `index.html` in a browser.

## Publish with GitHub Pages
1. Create a new public repository on GitHub, for example `after-hours-isaac-abel`.
2. Upload `index.html` and this `README.md` to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then press **Save**.
6. Wait a minute or two; GitHub will show the published URL under Settings → Pages.

## Features
- Responsive phone UI with lock screen and live clock
- Isaac / Abel point-of-view switch
- Interactive Messages, Memories, Notes, Music, Contacts, Profile, Phone and Diary apps
- Add messages and save notes locally in the browser
- Data is fictional and saved only in this browser using localStorage

## Customize
Everything is in `index.html`. Search for `profiles`, `conversations`, or `renderApp` to change the characters, chat lines, app content and visual details.

Fonts load from Google Fonts; if unavailable, the page falls back to system fonts.
